# Mochilas

Mochilas guardam itens extras, ganham melhorias e continuam com você quando você morre.

## Tipos

Todas são feitas na **bancada**. A mochila é um item que você usa na mão (não é vestida).

| Mochila | Espaço |
| --- | --- |
| Bolsa | 9 espaços |
| Mochila | 18 espaços |
| Ferro | 36 espaços |
| Ouro | 45 espaços |
| Esmeralda | 54 espaços |
| Diamante | 2 páginas |
| Netherite | 4 páginas de baú grande |

Quanto melhor a mochila, mais espaços de melhoria ela tem.

## Melhorias

| Melhoria | O que faz |
| --- | --- |
| Magnético | Puxa os itens do chão para a mochila |
| Água e Lava | Guarda água e lava num menu próprio |
| Fornalha | Fornalha portátil |
| Bancada | Bancada portátil |
| Ender Chest | Abre seu baú do End |
| Regeneração, Pressa, Velocidade | Efeitos enquanto a mochila estiver com você |
| XP | Mais experiência |
| Gerador de XP | Gera experiência com o tempo |
| Empurrão | Empurra os inimigos quando você fica com metade da vida |

- As melhorias de efeito têm **nível 1 a 3**. Junte **duas iguais** na **mesa de ferraria** para fazer o nível seguinte.
- Só o **Molde de Melhoria** tem receita. Molde + melhoria = melhoria pronta para colocar.

> Atenção: só a sua mochila **principal** dá os efeitos. Se você colocar melhoria em outra, o chat avisa.
