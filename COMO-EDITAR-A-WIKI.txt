COMO EDITAR A WIKI DA REDE ASTRAL
=================================

Você pode editar de dois jeitos:
  A) DENTRO DO SITE (recomendado): botão "Editar esta página", com prévia ao lado.
  B) PELO GITHUB: abrindo os arquivos no github.com (jeito antigo, sempre funciona).
Os dois salvam no mesmo lugar. Depois de salvar, o site público atualiza em 1 a 2 minutos
(se não aparecer, aperte Ctrl+F5 no PC ou feche e abra a página no celular).


A) EDITAR DENTRO DO SITE
========================

PRIMEIRA VEZ: criar a chave (token clássico) — só uma vez
  1. Entre no GitHub e abra:  https://github.com/settings/tokens/new
  2. Note: "editor do site". Expiration: escolha a validade (ex.: 1 ano).
  3. Em "Select scopes", abra o grupo "repo" e marque SOMENTE "public_repo".
     NÃO marque a caixa "repo" inteira: ela daria acesso também ao redeastral-servidor (privado).
  4. Generate token. Copie o código que começa com ghp_ (ele só aparece uma vez).

  IMPORTANTE: essa chave é como uma senha do site.
  - Não mande para ninguém, nem para mim, e não coloque no config.js.
  - Com public_repo ela só mexe nos seus repositórios públicos, não no redeastral-servidor.
  - Se vazar: no GitHub, Settings -> Developer settings -> Personal access tokens -> Tokens (classic) -> apague a chave.

ENTRAR NO MODO EDITOR
  Jeito rápido: botão da engrenagem (no topo do site) -> "Entrar no modo editor".
    Nos aparelhos onde você já entrou como editor, ele aparece sozinho. Num aparelho novo,
    clique na chavezinha bem pequena no canto de baixo do painel (ao lado de
    "Fica salvo só neste aparelho") ou toque 5 vezes na palavra "Configurações".
    Já logado, a engrenagem mostra "Editar esta página" em QUALQUER página do site
    (página inicial e Wiki), igual nas duas.
  Ou:
  1. Abra o endereço direto (salve nos favoritos):
        https://itzpowerytgfx.github.io/redeastral-site/wiki.html#modo-editor
     O link "Área do editor" no rodapé fica escondido para o público: ele só aparece
     nos aparelhos onde você já entrou como editor pelo menos uma vez.
  2. Repositório: SEU-USUARIO/redeastral-site
     Chave: cole o ghp_...
  3. Entrar. O modo editor já liga.
  Fica salvo só neste navegador. Em outro celular ou PC, entre de novo com a mesma chave.
  Jogadores não veem nada disso; sem a chave ninguém edita.

LIGAR E DESLIGAR A EDIÇÃO NA WIKI (igual à página inicial)
  Logado, a Wiki mostra a barra roxa embaixo. Para editar: "Editar esta página" na barra
  de baixo OU na engrenagem. Aí aparecem a barra de cima (Organizar, Nova página, Links...),
  os lápis e o "✥ Mover", e tudo fica com contorno tracejado.
  Com a edição ligada, toda página da Wiki que você abrir já abre editável.
  "Parar de editar" (barra de baixo) volta a mostrar a Wiki normal.

EDITAR UMA PÁGINA (escrevendo direto nela)
  Com a edição ligada, abra a página. Clique em qualquer texto e escreva:
  títulos, parágrafos, itens de lista, células de tabela, caixas de Dica/Atenção e
  legendas de imagem.
    Enter numa lista  -> item novo embaixo. Apagar tudo de um item vazio -> some.
    Negrito           -> selecione as palavras e clique em Negrito.
    Link              -> selecione as palavras, clique em Link, cole o endereço ou escolha
                         uma página da Wiki e clique em Inserir.
    Texto, Título, Título pequeno, Lista, Dica, Imagem, Vídeo, YouTube... -> entram logo
                         DEPOIS do que você clicou por último na página (sem nada clicado,
                         vão para o fim). Texto e títulos novos já ficam selecionados:
                         é só escrever por cima.
    Os mesmos botões ficam também na barra roxa de baixo ("Colocar:"), sempre à mão
    sem precisar subir a página. No celular a barra fica só com eles + Salvar.
    Linha divisória   -> separa um assunto do outro (linha roxa com ✦ no meio). Pode
                         escrever um título no meio dela (ex.: "Comandos") ou deixar só
                         a linha. No texto puro: "---" ou "--- Comandos".
  Clique em SALVAR (em cima, do lado de "Fechar editor", ou o "Salvar" da barra de baixo:
  os dois gravam a página). Até salvar, nada muda no site: aparece "● Não salvo" em
  laranja e a barra de baixo avisa "ainda NÃO estão no site".
  Se sair sem salvar, o texto fica guardado como rascunho SÓ neste navegador; abra a
  página de novo no editor e clique em Salvar.
  "Texto (avançado)": no computador fica do lado direito; no celular é o botão de cima.
  É o texto puro da página. Cartões de classe/habilidade se mudam por ali.

PÁGINA ESCONDIDA (só editores veem) — para preparar algo antes de anunciar
  No editor da página: botão "Esconder do público" (do lado do Salvar) -> Salvar.
  A página some do menu, dos cartões, da busca e do Anterior/Próxima para os jogadores.
  Quem entrou como editor continua vendo, com a etiqueta laranja "🔒 oculta".
  Para mostrar a todos: abra a página no editor -> "🔒 Escondida · Publicar" -> Salvar.
  (No texto puro é a linha <!-- oculta -->. O arquivo .md fica no GitHub, que é público: quem
  procurar o arquivo direto no GitHub consegue ler. Não guarde segredo de verdade em página escondida.)

MENU DO LADO (lista de páginas) — com a edição ligada
  ⠿ (pontinhos verdes) do lado de uma página: segure e arraste para cima/baixo ou para
     outra categoria (solte no nome dela = vai para o começo; embaixo dela = vai para o fim).
  ⠿ do lado do nome de uma categoria: arraste para mudar a ordem das categorias.
  Nome da categoria: clique nele, escreva e aperte Enter (Esc desiste).
  + (ao lado da categoria): cria uma página nova já dentro dela (escreva o título e
     clique em "Criar e editar"). "+ Nova página" no fim do menu: escolhe a categoria.
     No início da Wiki, cada categoria tem o botão "Nova página aqui".
  A–Z (ao lado da categoria): ordena as páginas dela de A a Z.
  "Tudo de A a Z" (no fim do menu): ordena as páginas de A a Z dentro de cada categoria.
  "+ Nova categoria": cria uma no fim; escreva o nome e arraste páginas para ela.
  ✕ aparece só em categoria vazia, para apagar.
  ⧉ (aparece ao passar o mouse numa página; no celular fica sempre): COPIAR para outra
     categoria. A mesma página passa a aparecer nas duas (ex.: um plugin em "Mecânicas" e
     em "Comandos"). É a mesma página: editar uma muda as duas. A cópia aparece com ↪ no
     menu e com a etiqueta "cópia" no cartão (só para você). O ✕ da cópia tira só a cópia.
  Tudo isso salva sozinho na hora (muda também a ordem dos cartões no início da Wiki).

APAGAR PARTES FIXAS DA WIKI (com a edição ligada)
  Passe o mouse (ou toque) em: "Anterior/Próxima" no fim das páginas, "Faltou alguma
  coisa?", a trilha "Wiki › Categoria", a pesquisa, "Início"/"Como entrar"/"Discord" do
  topo, o "Wiki" do logo, "Início da wiki" do menu do lado ou o rodapé.
  Aparece o botão vermelho "✕ Apagar". Para você ele fica apagadinho (tracejado vermelho);
  quem visita não vê mais. Errou? O mesmo botão vira "↺ Mostrar de novo".
  Depois clique em "Salvar" (barra de baixo).
  Páginas do menu do lado: ✕ ao lado da página (clique 2 vezes: "Tirar?") tira do menu.
  O arquivo fica guardado: volta por Organizar páginas → Fora do menu.

TEXTOS FIXOS DA WIKI (menu do topo, rodapé, rótulos)
  Com a edição ligada, também dá para escrever direto em: "Wiki" do logo, "Início" e
  "Como entrar" do menu, texto do botão do Discord, "Todas as páginas" (celular),
  "Início da wiki" do menu do lado, "Wiki" da trilha em cima do título, "Anterior" e
  "Próxima", "Faltou alguma coisa?..." e o rodapé. Também o texto dentro da pesquisa
  (campo "Texto dentro da caixa de pesquisa").
  Clicando em "Início" ou "Como entrar", aparece "Link do botão:" na barra de baixo.
  Depois clique em "Salvar" (barra de baixo). "Cancelar" desfaz.

BOTÕES DO EDITOR
  Título      -> subtítulo de seção
  Negrito     -> marque o texto e clique
  Lista       -> lista com tracinhos
  Dica        -> caixa verde
  Atenção     -> caixa laranja
  Tabela      -> tabela pronta para preencher
  Link        -> escreva o texto e o endereço (https://...) OU escolha outra página da Wiki
  Imagem      -> escolha a imagem do computador/celular; ela é enviada e já entra no texto.
                 Troque "Escreva a legenda aqui" pela legenda.
  Vídeo .mp4  -> igual à imagem (até 25 MB). Fica parado com botão de play.
  Animação    -> envie um .mp4 curto: ele toca sozinho, em LOOP, sem som e sem controles,
                 igual a um GIF, só que bem mais leve. Ótimo para mostrar comando e menu.
  YouTube     -> cole o link do vídeo. Shorts aparecem em pé.
  Depois de enviar imagem ou vídeo, clique em SALVAR.

CARTÕES COM ÍCONES (classes, raças, habilidades, atributos)
  Botão "Cartão" no editor. Ele escreve isto (troque pelos dados certos):
      ::: classe Guerreiro
      habilidades: Espadas, Machados, Defesa
      atributos: +3 Força, -2 Vida
      especial: **Fúria de Batalha**: +12% de dano com pouca vida.
      :::
  Troque "classe" por "raca" para raça (aceita a linha  tamanho: 85% ).
  Para um cartão de uma habilidade ou atributo sozinho:
      ::: atributo Força
      valor: +1% por ponto, até 60%
      texto: o que ele faz
      :::
  Cartões seguidos ficam lado a lado. O ícone aparece sozinho pelo nome
  (Mineração, Lenhador, Escavação, Agricultura, Pesca, Espadas, Machados, Desarmado,
  Arqueria, Armas Pesadas, Defesa, Acrobacia, Alquimia, Encantamento, Domesticação,
  Forja, Culinária, Força, Vida, Regeneração, Sorte, Sabedoria, Resistência, Agilidade,
  Precisão, Pets). Atributo com + fica verde e com - fica vermelho.
  As imagens dos ícones ficam em img/icones/ (um arquivo .svg para cada).

APAGAR (botão vermelho "✕ Apagar", ao lado do "✥ Mover")
  No editor de uma página, passe o mouse (ou toque) no que quer tirar: vídeo, YouTube,
  imagem, texto, lista, tabela, caixa, colunas lado a lado. Clique em "✕ Apagar".
  Errou? Clique em "Desfazer" logo embaixo dos botões. Depois clique em Salvar.
  O arquivo do vídeo/imagem continua guardado na pasta midia (não aparece em lugar nenhum).

MOVER E COLOCAR LADO A LADO (botão verde "✥ Mover")
  Na página (editor aberto), passe o mouse (ou toque) em qualquer coisa: texto, título,
  imagem, vídeo, lista, tabela, cartão. Aparece o botão verde "✥ Mover" no canto de cima.
  Segure e arraste. Uma linha verde mostra onde vai cair:
  - em cima ou embaixo de outra coisa  -> muda a ordem;
  - na beirada ESQUERDA ou DIREITA de outra coisa -> fica uma do lado da outra (colunas).
    Dá para pôr 3 ou mais lado a lado: é só soltar na beirada de uma coluna.
  Para tirar do lado a lado, arraste para cima ou para baixo de algo fora das colunas.
  Depois clique em SALVAR. Errou? Ctrl+Z no "Texto (avançado)" desfaz.
  No celular as colunas ficam uma embaixo da outra quando não cabem na tela.

  No texto, o lado a lado fica assim (o botão "Lado a lado" escreve isto pronto):
      ::: lado
      ![Primeira imagem](midia/foto1.png)
      +++
      ![Segunda imagem](midia/foto2.png)
      :::
  Cada +++ separa uma coluna. Dentro de uma coluna pode ter texto, imagem, vídeo, lista...

AUMENTAR / DIMINUIR (bolinha roxa)
  Na página (editor aberto), passe o mouse (ou toque) em um título, parágrafo, lista, tabela,
  caixa de dica, imagem ou vídeo.
  Aparece uma bolinha roxa no canto: arraste para a DIREITA para aumentar e para a ESQUERDA para diminuir.
  Texto: de 50% a 300%. Imagem e vídeo: de 10% a 100% da largura da página.
  Duplo clique na bolinha volta ao tamanho normal. Depois clique em SALVAR.
  (No texto aparece no fim da linha algo como {70%}. Pode apagar para voltar ao normal.)

LÁPIS E "MOVER" NA PÁGINA INICIAL DA WIKI (cartões)
  Com a edição ligada, a página inicial da Wiki mostra botões verdes "✥ Mover" e roxos com lápis.
  "✥ Mover" num cartão: segure e arraste para o lado de outro cartão (muda a ordem) ou para
    outra categoria (o cartão vai para o fim dela). Salva sozinho na hora.
  "✥ Mover" ao lado do nome da categoria: arraste para cima ou para baixo de outra categoria.
  Categoria vazia continua aparecendo para você (só para o editor), para dar para arrastar cartões para ela.
  - "Editar" em cada cartão -> muda o título, o resumo (texto pequeno) e a capa do cartão.
    Capa: "Escolher imagem" envia uma foto; "Sem capa" tira; "Automática" usa a
    primeira imagem da página. O título e o resumo também mudam dentro da página.
    "Editar a página inteira" abre o editor completo.
  - "Renomear / organizar" ao lado de cada categoria -> abre o "Organizar páginas".
  - "Editar título e texto" no topo -> abre o "Editar início da Wiki".

INÍCIO DA WIKI (título e texto do topo)
  Barra roxa -> "Editar início da Wiki". O título é a linha com # e o resto é o texto
  que aparece embaixo dele. Aceita negrito, link, imagem, vídeo e cartões, igual às páginas.

ORGANIZAR PÁGINAS E CATEGORIAS
  Barra roxa -> "Organizar páginas". Ali dá para:
  - renomear uma categoria (clique no nome dela e escreva);
  - subir/descer categorias e páginas com as setas;
  - mudar uma página de categoria pela lista ao lado dela;
  - tirar uma página do menu com o X (ela vai para "Fora do menu" e não é apagada;
    "Voltar ao menu" traz de volta);
  - "+ Nova categoria"; o X de uma categoria só apaga se ela estiver vazia.
  Nada muda até clicar em Salvar.

NOVA PÁGINA
  Barra roxa -> "Nova página" -> título e categoria (ou "+ Nova categoria").
  A página é criada, entra no menu e o editor abre.

LINKS DO DISCORD, DA LOJA, DO YOUTUBE E DO INSTAGRAM
  Barra roxa -> "Links do site" -> cole os links -> Salvar links.
  Vale para a página inicial e para a Wiki (botões do Discord e da loja e a aba Redes sociais).
  Enquanto um link estiver vazio, o botão/cartão mostra "Em breve".
  Os ícones da aba Redes sociais ficam em img/redes/ (youtube.webp, instagram.webp, discord.webp);
  para trocar, suba um arquivo .webp com o mesmo nome por cima.

SAIR
  Barra roxa -> "Sair". Apaga a chave deste navegador.

EDITAR A PÁGINA INICIAL (início do site)
  Com o modo editor ligado, a página inicial mostra uma barra roxa embaixo.
  1. Clique em "Editar esta página".
  2. Tudo que pode mudar fica com um contorno tracejado: clique e escreva ali mesmo.
     Títulos, textos, regras, punições, VIPs, perguntas, passos de "Como entrar", o rodapé,
     os textos dos BOTÕES e os nomes do MENU do topo e das abas.
     (o nome do menu muda junto no computador e no celular)
  3. Listas têm "+ Adicionar ..." no fim e um X vermelho em cada item para remover.
     Os cartões de sistemas mostram uma caixinha "Link:" para escolher qual página da Wiki abrem
     (ex.: wiki.html#mochilas).
     Ao clicar num botão, aparece na barra "Link do botão:": escreva para onde ele leva
     (#regras, #como-entrar, wiki.html#captura ou https://...).
     Botões do Discord e da loja pegam o link de "Links do site" (na Wiki); enquanto
     não tiver link, eles mostram "(em breve)" sozinhos.
  4. Negrito: selecione o texto e clique em Negrito.
     Link: selecione o texto, clique em Link, cole o endereço e aperte Enter.
  5. Clique em Salvar. Cancelar desfaz tudo que não foi salvo.
  MOVER QUALQUER COISA: clique nela; aparece o botão verde "✥ Mover" no canto de cima.
  Segure e arraste. Uma linha verde mostra onde vai cair (em cima, embaixo, à esquerda ou
  à direita de outra coisa). Para mover um bloco inteiro (ex.: o cartão todo, uma pergunta
  inteira das Dúvidas), use antes "Selecionar o bloco de fora". Arrastando perto do topo
  ou do fim da tela, a página rola sozinha. Depois clique em Salvar (Cancelar desfaz tudo).
  Tamanho de QUALQUER coisa (logo, cartão, caixa de IP, botão, ícone, texto):
  clique nela e arraste a bolinha roxa do canto (direita = maior, esquerda = menor,
  duplo clique = normal). O contorno verde mostra o que está selecionado.
  "Selecionar o bloco de fora" pega o que está em volta (ex.: clicou no título do cartão
  -> pega o cartão inteiro).

INSERIR IMAGEM, VÍDEO, TEXTO, TÍTULO E ABAS NOVAS (página inicial, qualquer aba)
  Com "Editar esta página" ligado, clique onde quer colocar e clique em "+ Inserir".
  ONDE (no topo do menu "+ Inserir"):
    Automático     -> selecionou uma CAIXA (cartão, balão, pergunta, caixa nova): entra DENTRO dela,
                      no fim. Selecionou um texto, título, imagem ou botão: entra logo DEPOIS dele.
    Dentro (no fim) / Dentro (no começo) / Depois / Antes -> escolha você mesmo.
    Sem nada selecionado, entra no fim da aba aberta. A barra diz onde o item entrou.
    Dica: clicou no título de um cartão e quer pôr a imagem dentro do cartão? Use
    "Selecionar o bloco de fora" antes (pega o cartão) ou escolha "Depois".
    Imagem / Vídeo .mp4 / Animação (loop)  -> escolha o arquivo (até 25 MB). Ele vai para a pasta
                                              midia/ do site. Imagem e vídeo têm legenda opcional.
    YouTube                                -> cole o link e aperte Enter
    Texto / Título                         -> escreva por cima de "Escreva aqui." / "Novo título"
    Caixa                                  -> um balão novo com título e texto. Selecione a caixa
                                              e insira imagem/vídeo: entra dentro dela. Com
                                              "Usar como fundo" vira o fundo da caixa.
    Nova aba                               -> nome e Enter: a aba entra no menu do topo (computador
                                              e celular) com título e texto para editar
  Depois dá para arrastar com "✥ Mover" e mudar o tamanho com a bolinha. Clique em Salvar.
  FUNDO: com uma imagem ou vídeo selecionado (ou o balão que tem a imagem/vídeo), clique em
  "Usar como fundo": ela cobre o balão inteiro, com uma camada escura para o texto aparecer.
  Vídeo de fundo toca sozinho, em loop e sem som. Para voltar: selecione o balão -> "Tirar do fundo".
  EFEITOS: selecione qualquer coisa e clique em "Efeitos":
    Opacidade 10-100%, Desfoque 0-100%, Sombra 0-100% + cor, Brilho 0-100% + cor.
    Sombra e brilho valem para o texto do que está selecionado (título, parágrafo, botão,
    ou um balão inteiro) e podem ser usados juntos. Duplo clique no nome volta ao normal.
    Num balão com imagem/vídeo de fundo, marque "só no fundo" para mudar só o fundo
    (ex.: fundo desfocado e mais transparente, com o texto nítido por cima).
  APAGAR: selecione e clique em "Apagar" e depois em "Confirmar apagar". As abas que você criou
  também podem ser apagadas (selecione a aba inteira com "Selecionar o bloco de fora").
  As abas que já vinham no site não podem ser apagadas, só o que está dentro delas.
  MENU: mover um item do menu do topo muda a ordem nos dois menus (computador e celular).
  Se as abas não cabem no topo, o site mostra o botão "Menu" sozinho.
  VOLTAR E AVANÇAR: botões ↶ e ↷ na barra roxa, ou Ctrl+Z (voltar) e Ctrl+Y ou Ctrl+Shift+Z
  (avançar). Voltam mover, inserir, apagar, efeitos, tamanho, fundo, links e o que você escreveu.
  Escrevendo dentro de um texto, Ctrl+Z desfaz primeiro as letras; clique fora e o ↶ volta
  o texto inteiro. Depois de Salvar a lista de voltar zera (o que foi salvo fica).
  Quebrou tudo e não salvou? Clique em Cancelar (ou recarregue a página): volta como estava.

EDITAR PELO CELULAR VENDO COMO NO COMPUTADOR
  Na barra roxa (página inicial ou Wiki): botão "Modo computador".
  A página passa a aparecer como no PC (dê zoom com os dedos). Para voltar: "Modo celular".
  Fica ligado neste celular até você desligar.

MOUSE VIRTUAL (touchpad na tela, para o celular)
  Na barra roxa (página inicial ou Wiki): botão "Mouse virtual". Aparece um touchpad e uma setinha.
  - Arraste 1 dedo no touchpad      -> move a setinha (rápido = anda mais)
  - Toque rápido no touchpad         -> clique
  - Toque e SEGURE meio segundo, depois arraste -> segura o clique e arrasta (solte o dedo para soltar)
  - Botão "Segurar"                  -> segura o clique até tocar de novo; dá para arrastar
                                        longe, levantando e colocando o dedo várias vezes
  - 2 dedos no touchpad              -> rola a página (ou o quadro que está embaixo da setinha)
  - Botão "Clique"                   -> clique onde está a setinha
  - Segure o título "Mouse virtual" e arraste para mudar o touchpad de lugar; "–" esconde.
  Funciona junto com o "Modo computador". Fica ligado neste aparelho até você esconder.
  Para escrever: clique no texto com o touchpad e use o teclado do celular.

STATUS DO SERVIDOR (página inicial)
  Na barra roxa da página inicial: "Status do Servidor:" com 4 botões.
  Automático -> o site pergunta ao servidor Java e mostra Online/Offline e quantos jogadores (padrão).
                O Bedrock acompanha o Java (é o mesmo servidor, pelo Geyser).
  Online     -> mostra Online mesmo que a consulta falhe.
  Offline    -> mostra Offline.
  Manutenção -> mostra "Em manutenção · volta em breve" (laranja).
  Salva na hora, sem precisar de "Editar esta página". Lembre de voltar para Automático depois.
  Ainda não dá para trocar pelo editor: a imagem da logo, os ícones dos cartões e os IPs
  (IPs e links do Discord/loja ficam em "Links do site" na Wiki ou no config.js).


B) EDITAR PELO GITHUB
=====================

ONDE FICA CADA COISA
  wiki/paginas.txt      -> a lista das páginas e categorias, na ordem do site
  wiki/xxxxx.md         -> o texto de cada página (um arquivo por página)
  wiki/midia/           -> as imagens e vídeos
  config.js             -> links do Discord, da loja, IPs e portas

COLOCAR IMAGEM
  1. Renomeie o arquivo SEM espaço e SEM acento, em minúsculas (ex.: rubi-na-caverna.png).
  2. Pasta wiki/midia -> Add file -> Upload files -> arraste -> Commit changes.
  3. Abra a página .md -> lápis (Edit) -> numa linha sozinha:
        ![Legenda da imagem](midia/rubi-na-caverna.png)
  4. Commit changes.

COLOCAR VÍDEO
  YouTube: cole o link sozinho numa linha.
  Arquivo: suba o .mp4 em wiki/midia (até 25 MB) e escreva sozinho numa linha:  midia/video.mp4
  Em loop, como GIF: escreva sozinho numa linha:  animacao: midia/video.mp4
  Tamanho: coloque no fim da linha  {70%}   ex.:  ![Legenda](midia/foto.png) {50%}   ou   ## Título {150%}

COLOCAR LINK NO TEXTO
  [texto que aparece](https://endereco.com)
  [outra página da wiki](captura.md)
  Um endereço https://... solto no meio da frase também vira link.

FORMATAÇÃO
  # Título da página            (um só, na primeira linha)
  ## Subtítulo
  **negrito**   *itálico*   `/comando`
  - item de lista
  1. passo numerado
  > Dica: texto                 (caixa verde)
  > Atenção: texto              (caixa laranja)
  | Coluna 1 | Coluna 2 |
  | --- | --- |
  | valor | valor |
  <!-- anotação que não aparece no site -->

  O primeiro parágrafo depois do título vira o resumo do cartão.
  A primeira imagem da página vira a capa do cartão.

CRIAR PÁGINA PELO GITHUB
  1. Pasta wiki -> Add file -> Create new file -> nome sem espaço/acento terminando em .md
  2. Primeira linha:  # Título
  3. Abra wiki/paginas.txt e coloque o nome do arquivo embaixo da categoria.


SE ALGO DER ERRADO
==================
  "Chave inválida ou vencida"      -> crie uma chave nova e entre de novo.
  "não tem permissão de escrita"   -> a chave precisa de Contents: Read and write.
  "Imagem não encontrada"          -> o nome entre ( ) está diferente do arquivo em wiki/midia.
  "O arquivo ... não foi encontrado" -> o nome no paginas.txt está diferente do arquivo .md.
  Vídeo do YouTube não aparece     -> o link precisa estar SOZINHO na linha.
  Salvei mas não mudou             -> espere 2 minutos e aperte Ctrl+F5.
  Errou feio?                      -> no GitHub, abra o arquivo -> History -> volte uma versão.


ANÚNCIOS (carrossel no Início)
==============================
As imagens que passam no Início ficam no arquivo anuncios.json (na raiz do site).
  - Imagem nova: envie para a pasta midia/anuncios/. São 2 tamanhos:
      PC: larga, 1920x600 (16:5).  Celular: 1600x900 (16:9) - opcional, sem ela o celular usa a do PC.
  - Abra anuncios.json e copie um bloco { ... } dentro de "slides", trocando:
      "imagem": "midia/anuncios/NOME-largo.webp"          (a do PC)
      "imagem_celular": "midia/anuncios/NOME.webp"        (a do celular)
      "titulo": "texto que descreve a imagem"
      "link":   "wiki.html#pagina"   (opcional: para onde vai ao clicar; pode ser o Discord também)
      "ativo":  true                 (false esconde sem apagar)
      "ate":    "2026-12-31"         (opcional: some sozinho depois dessa data)
  - A ordem dos blocos é a ordem dos slides. "segundos" = tempo de cada slide.
  - Sem nenhum slide ativo, o carrossel não aparece.
